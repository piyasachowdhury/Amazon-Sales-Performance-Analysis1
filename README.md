# Amazon-Sales-Performance-Analysis1
End-to-end Amazon sales performance analysis using Excel and Power BI, covering data cleaning, business analysis, and interactive dashboard development.

## 📌 Project Overview

This project analyses Amazon sales data to understand overall sales performance, revenue trends, product and category performance, geographic performance, and operational outcomes.

The analysis was completed using Excel and Power BI, following an end-to-end analytics workflow from data cleaning and exploratory analysis to business analysis and interactive dashboard development.

## 🎯 Business Objective

The objective of this project is to analyze Amazon sales data and identify key patterns in revenue, product performance, customer demand, geographic distribution, and order outcomes.

The analysis aims to answer business questions such as:

- Which product categories generate the most revenue and sales?
- Which states contribute the highest number of orders?
- How does revenue change over time?
- What are the major order-status outcomes?
- How do fulfilment methods and shipping service levels relate to order outcomes?
- Which product sizes and styles are most frequently ordered?
- How does B2B performance compare with consumer sales?

- ## 🛠️ Tools Used

- **Microsoft Excel** — Data cleaning, PivotTables, PivotCharts, exploratory analysis, and dashboard development
- **Power BI** — Interactive data visualization and dashboard development
- **DAX** — Measures and KPI calculations in Power BI.

- ## 📊 Dataset

The dataset contains Amazon sales transaction records, including information on:

- Order details and dates
- Product categories and sizes
- Sales amount and quantity
- Customer states
- Fulfilment methods
- Shipping service levels
- Courier and order statuses
- B2B and consumer orders
- Product styles

- ## 🔄 Project Workflow

### 1. Data Cleaning

The raw dataset was cleaned and prepared in Excel before analysis. This included handling inconsistent date formats, standardizing state and category names, checking data consistency, and preparing the dataset for analysis.

### 2. Exploratory Analysis

The cleaned dataset was explored using Excel PivotTables and PivotCharts to examine revenue, sales quantity, product categories, geographic performance, order statuses, fulfilment methods, shipping service levels, and customer segments.

### 3. Business Analysis

Key business questions were analyzed to identify trends and patterns in sales performance, including revenue trends, top-performing categories and states, order outcomes, cancellation and return patterns, size preferences, product performance, and B2B versus consumer sales.

### 4. Dashboard Development

An interactive Excel dashboard was created using KPI metrics, PivotCharts, and slicers.

A Power BI dashboard was then developed using DAX measures, KPI cards, interactive slicers, and data visualizations to present the key findings in an easy-to-understand format.

## 📈 Key Insights

- Total revenue generated was **₹78.59M** across **128,975 sales records**.
- **Set** was the highest-revenue category, contributing approximately **₹39.20M** in revenue.
- **Maharashtra** recorded the highest number of orders among the states analyzed.
- **April 2022** recorded the highest monthly revenue, followed by May and June.
- **M** was the most frequently ordered size, followed by **L** and **XL**.
- **Amazon fulfilment** recorded a lower cancellation rate than Merchant fulfilment.
- **Standard** shipping recorded a higher cancellation rate than Expedited shipping.
- **Consumer sales** accounted for the vast majority of records and revenue, while B2B represented a smaller share.
- The analysis also examined product styles, order-status outcomes, cancellations, and returns to identify operational patterns.
